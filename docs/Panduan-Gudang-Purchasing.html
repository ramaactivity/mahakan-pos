1. Halaman Bahan Baku

Login → menu Inventory → Bahan Baku

Yang Baru

  • Ada toggle "Snapshot" ↔ "Pergerakan Bulan" di pojok kanan atas
  • Snapshot = stok sekarang (mode lama, default)
  • Pergerakan Bulan = BARU. Per bulan: Stok Awal + Pembelian + Stok Akhir + HPP

Cobain Dulu

  1. Klik "Pergerakan Bulan"
  2. Pilih bulan (default bulan ini)
  3. Lihat tabel: tiap bahan ada Stok Awal Bulan → Pembelian → Stok Akhir → Pemakaian → Nilai HPP
  4. Klik salah satu bahan → modal drill-down keluar: list semua gerakan bulan itu (Pembelian, Pemakaian POS, Waste, Adjust, Refund Restore)
  5. Coba tombol "Unduh CSV" — format mirip Google Sheets COGS dulu
Yang perlu diperhatikan:
  • Banner kuning "X bahan belum punya opname awal bulan" → stok awal belum akurat. Perlu Stok Opname.
  • Status badge: Akurat punya opname awal · Partial sebagian · No baseline belum ada opname

2. Stok Opname

Menu Inventory → Stok Opname

Kapan Opname?

  • WAJIB tanggal 1 tiap bulan → supaya "Stok Awal Bulan" akurat
  • Boleh juga akhir hari untuk bahan kritikal (kopi, susu, daging)

Caranya

  1. Klik "Buat Opname Baru"
  2. Pilih bahan yang mau di-count (boleh sebagian atau semua)
  3. Input qty fisik (yang kamu timbang/hitung di gudang)
  4. Sistem otomatis tampil selisih vs sistem
  5. Kasih alasan kalau selisih > 5% (mis. "waste cup retak", "tumpah")
  6. Simpan
Selisih besar tanpa alasan jelas → cek "Pergerakan Bulan" drill-down bahan itu, telusuri ada gerakan ganjil tidak.

3. Purchase Request (PR) — Permintaan Beli

Menu Purchasing → PR

Konsep Singkat

  • Staff/kasir sadar bahan menipis → buat PR
  • Owner approve
  • Kamu (purchasing) catat pembelian dari PR itu

Yang Baru di PR List

  • Tiap PR sekarang tampil sebagai card ringkas (bukan wall-of-text lagi)
  • Tampil: status badge, nama requester+tanggal, jumlah item, progress bar hijau (% sudah diterima)
  • Klik card → modal detail keluar, baru lihat item & aksi

Status PR

  • Draft belum approve owner
  • Open siap dibeli
  • Partial sudah ke-terima sebagian
  • Closed sudah ke-terima semua
  • Cancelled batal

4. Tarik PR ke Pembelian ★ FITUR PENTING

Skenario lama: PR approved → kamu buat Pembelian baru → ketik ulang nama bahan + qty satu per satu. Ribet kan?
Skenario baru: PR approved → klik "Tarik ke Pembelian" → form auto-isi semua item dari PR. Tinggal centang & submit.

Cara A — dari Halaman Pembelian

  1. Menu Inventory → Pembelian
  2. Klik tombol "Tarik dari PR" (samping tombol "Catat Pembelian")
  3. Step 1: Pilih PR dari list (urut dari yang paling lama dulu)
  4. Step 2: Form muncul dengan semua item PR sudah ke-isi
  5. Centang/uncentang item yang mau dibeli batch ini (boleh partial!)
  6. Supplier auto-suggest dari Market List → ada badge "Auto" muncul. Kamu boleh ganti per baris.
  7. Edit qty / harga kalau beda dari PR (mis. supplier kasih lebih murah)
  8. Lihat preview groups: "3 pembelian akan dibuat: Supplier A Rp 250rb · Supplier B Rp 180rb · Supplier C Rp 95rb"
  9. Klik Simpan → semua pembelian dibuat sekaligus

Cara B — dari Modal Detail PR

  1. Menu Purchasing → PR
  2. Klik card PR (status Open atau Partial)
  3. Modal detail keluar → klik tombol "Tarik ke Pembelian"
  4. Langsung ke Step 2 wizard (skip pilih PR, kan udah dipilih)

Multi-Vendor Split — Gimana Kerjanya?

Misal 1 PR isinya: Susu (dari supplier A), Kopi (dari supplier B), Gula (dari supplier C). Sistem auto-grouping per supplier → buat 3 pembelian terpisah sekaligus. Tiap supplier dapat nota sendiri-sendiri (rapi buat akuntansi).

Catat Partial

  • PR minta 10 Kg kopi, hari ini supplier cuma kasih 6 Kg
  • Centang item kopi, edit qty jadi 6
  • Submit → PR otomatis update jadi Partial (outstanding masih 4 Kg)
  • Besok supplier kirim 4 Kg sisanya → tarik PR yang sama lagi → tinggal 4 Kg outstanding

5. Catat Pembelian Langsung (Tanpa PR)

Kalau beli dadakan tanpa PR (mis. mendadak kehabisan, beli di pasar):

Menu Inventory → Pembelian → klik "Catat Pembelian"

Form mirror Google Sheets COGS (yang biasa Cacil/Anisa pakai):

  • Pilih supplier (atau "Pembelian Langsung" untuk pasar)
  • Tambah baris bahan
  • Input qty + harga total per baris
  • Sistem hitung otomatis subtotal

Unit Conversion — INI PENTING (buat Cacil & Anisa)

Saat input qty, ada preview LIVE di bawah field:

Warna PreviewContoh PesanArtinya
Hijau ✓"≈ 2.000 gr (master)"Aman, sistem auto-convert
Hijau via-pack"via Market List: 1 Pack = 25.000 gr"Aman, ada Pack Size
Kuning ⚠"Set Pack Size dulu di Market List"Setup Market List dulu
Merah ⛔"Tidak compatible"Unit beda dimensi (gr vs liter)

Contoh Skenario

Skenario 1 — Same Dimension:
  • Master kopi di sistem: gram
  • Kamu beli "2 Kg kopi" → input qty 2, pilih unit "Kg"
  • Preview hijau muncul: "≈ 2.000 gr (master)"
  • Stok sistem nambah 2.000 gr (BUKAN 2 doang!). Sebelum update ini bisa salah jadi cuma +2, sekarang aman.
Skenario 2 — Via Pack:
  • Master tepung: gram
  • Kamu beli "1 Pack tepung 25 Kg" dari Supplier A
  • Pertama kali: setup di Market List dulu → supplier A × tepung → Pack Size = 25, Pack Unit = Kg
  • Setelah setup, input qty 1, unit "Pack" → preview "via Market List: 1 Pack = 25.000 gr" → stok +25.000 gr
  • Sekali setup, selamanya bebas catat pakai "Pack"
Tips gaptek:
  • Tidak yakin unit-nya? Liat preview. Hijau = lanjut. Kuning/merah = stop, fix dulu.
  • Selalu cek total Rp di bawah sebelum simpan — match sama nota fisik
  • Upload bukti foto nota — auto-save ke Google Drive folder STRUK PEMBELIAN

6. Market List (Setup Pack Size)

Menu Inventory → Market List

Apa itu? Tabel kombinasi: Supplier × Bahan + harga + pack info.

Kapan Perlu Setup?

  • Bahan yang sering dibeli dalam pack: Tepung 25Kg, Beras 50Kg, Susu UHT 1L, Minyak 5L
  • Setup sekali → forever bisa pakai unit "Pack"

Cara Setup

  1. Cari kombinasi supplier × bahan (atau klik "Tambah Entry")
  2. Isi:
    • Pack Size: 25
    • Pack Unit: Kg
    • Harga Per Pack: Rp X
  3. Centang "Primary supplier" kalau ini supplier utama untuk bahan ini → akan auto-suggest saat tarik PR
  4. Simpan

7. FAQ Gaptek

Q: Pembelian sudah dicatat tapi stok kelihatan aneh?
Cek "Pergerakan Bulan" → klik bahan itu → drill-down. Pasti ketauan: salah unit input, ada waste tidak tercatat, atau qty kebalik.
Q: PR sudah approve tapi tidak muncul di "Tarik dari PR"?
Status PR harus Open atau Partial. Kalau "Draft" = belum approve. Kalau "Closed" = sudah ke-terima semua.
Q: Setelah Tarik PR salah, mau batal?
Buka Pembelian yang baru dibuat → klik Cancel. PR otomatis revert outstanding-nya, bisa di-tarik ulang.
Q: Beli barang yang belum ada di master bahan?
Setup bahan dulu di Bahan Baku → "Tambah Bahan". Kasih unit dasar:
  • Timbangan → gram
  • Cairan → ml
  • Butiran/biji → pcs
Setelah save, baru bisa catat pembelian-nya.
Q: Ada bahan yang stok-nya minus / merah?
Dashboard Bahan Baku → card "Stok Negatif" warna merah. Artinya ada penjualan tapi belum catat pembelian, atau salah unit dulu. Drill-down untuk telusuri & koreksi via opname.
Q: Opname sudah disimpan tapi stok minus belum hilang?
Opname koreksi stok sistem = stok fisik kamu. Kalau masih minus berarti tanggal opname belum match atau ada flow yang belum di-save. Cek tanggal opname.
Q: Preview unit kuning "Set Pack Size dulu" — gimana?
Berarti kombinasi Supplier × Bahan ini belum ada Pack Size di Market List. Dua pilihan:
  1. Ganti unit input ke unit master (gr/ml/pcs) — langsung jalan
  2. Setup Market List dulu (sekali setup, forever)
Q: Multi-vendor split — kalau salah satu supplier kasih barang nya beda dari PR?
Step 2 wizard kamu bisa edit qty/harga per baris sebelum submit. Tidak harus match PR persis.

8. Urutan Pakai Harian (Routine)

Pagi (5 menit)

  • Buka Bahan Baku → cek card Stok Rendah & Stok Negatif
  • Yang merah = prioritas hari ini (telp supplier atau buat PR)

Saat Ada PR Baru

  • Menu PR → review yang status Open
  • Tunggu supplier datang → Tarik ke Pembelian

Saat Terima Barang dari Supplier

  • Tarik dari PR (kalau ada PR-nya) atau Catat Langsung (kalau dadakan)
  • WAJIB cek preview unit conversion harus hijau ✓
  • Input qty match nota
  • Upload foto nota (untuk audit Owner)

Akhir Hari (5 menit)

  • Buka Pergerakan Bulan → cepat scan ada bahan yang "aneh" pemakaiannya tidak?
  • Kalau ada selisih besar → opname spot bahan itu

Awal Bulan (WAJIB, 30 menit)

  • Stok Opname semua bahan utama
  • Ini yang bikin "Stok Awal Bulan" akurat untuk laporan COGS

9. Yang Sering Bikin Salah (Hindari!)

  • JANGAN input qty pakai unit yang gak dimengerti sistem. Selalu liat preview, harus hijau.
  • JANGAN skip opname awal bulan. Pergerakan Bulan jadi gak akurat → laporan HPP melenceng.
  • JANGAN catat 2× untuk barang yang sama (mis. tarik dari PR + catat langsung). Cek dulu.
  • JANGAN delete pembelian kalau cuma mau koreksi qty — pakai Edit. Delete cuma kalau bener-bener batal.
